## Headline: jWhiteboard CWM API crash (0.1.41 image)

First **0.1.41** GHCR builds crash-looped Joshu API on clean provision:

```text
ERR_MODULE_NOT_FOUND: Cannot find module '/opt/joshu/dist/excalidraw/errors.js'
  imported from dist/excalidrawApi.js
```

ArozOS `:8787` stayed up; Caddy returned **502** on `/joshu/*`.

| Cause | Detail |
|-------|--------|
| Build order | `npm run build:deploy` runs root `tsc`, then `build:excalidraw` |
| Vite | `apps/excalidraw/vite.config.ts` uses `outDir: "../../dist/excalidraw"` + **`emptyOutDir: true`** |
| Effect | Vite wiped tsc output (`errors.js`, `paths.js`, `scene.js`, `service.js`, `store.js`) — image kept only `index.html` + `assets/` |
| Lucky fleet boxes | Host `dist/excalidraw/*.js` from an older laptop build survived `docker cp` sync (non-destructive overlay) |

**Fix (commit `67206ff`):**

| Layer | Change |
|-------|--------|
| `package.json` | `build:excalidraw` — Vite, then **`tsc -p tsconfig.json`** |
| `scripts/vps-build-image.sh` | Fail closed if `dist/excalidraw/errors.js` or `service.js` missing |
| `scripts/sync-dist-from-image.sh` | Copy `deploy/hotfixes/cwm-backend-js/` when pulled image still lacks `errors.js` |
| `deploy/hotfixes/cwm-backend-js/` | Compiled fallback JS + README |
| GHCR | **2026-08-22** local rebuild overwrote `:0.1.41`, `:latest`, `:v0.1.41` / `:v0.1.41-oss` |

**Do not** wipe host `dist/excalidraw/*.js` on live boxes until the rebuilt image is pulled and synced.

Docs: [`hetzner-quickstart.md`](../vps-sandbox/hetzner-quickstart.md) troubleshooting row · [`jwhiteboard-developer-guide.md`](../jwhiteboard-developer-guide.md).

## Headline: Voice dictation sessions (lists, notes, rambling)

Multi-pause dictation (website lists, meeting notes, rambling thoughts) used to fail: each VAD silence ended an **organic** turn, STT heard the chunks, but Hermes never wrote a file.

**Fix:** Realtime tools `start_dictation` / `finish_dictation` / `cancel_dictation`. Joshu buffers every user transcript while the session is active (organic speech suppressed), then one Hermes job formats and stores:

| Format | Use |
|--------|-----|
| `cleanup` | Lists / light edit (normalize URLs, bullets, dedupe) |
| `reformulate` | Meeting notes / rambling → clear prose |
| `auto` | Hermes chooses from content |

Done via `finish_dictation` or a clear done phrase (*that's it*, *I'm done*, …). Browser + PSTN.

| Piece | Detail |
|-------|--------|
| Buffer | [`dictationSession.ts`](../../packages/voice-realtime/src/dictationSession.ts) |
| Tools / prompts | [`realtimeTools.ts`](../../packages/voice-realtime/src/realtimeTools.ts), [`joshuIdentity.ts`](../../packages/voice-realtime/src/joshuIdentity.ts) |
| Orchestration | [`browserRealtimeSession.ts`](../../packages/voice-realtime/src/browserRealtimeSession.ts), [`twilioRealtimeSession.ts`](../../packages/voice-realtime/src/twilioRealtimeSession.ts) |

Doc: [`voice-think-speak.md` — Dictation sessions](../vps-sandbox/voice-think-speak.md#dictation-sessions-lists-notes-rambling).

## Headline: EA owner-reply child

Owner mail to the **agent Nylas** inbox with a non-meeting ask used to **file** correctly (`ea-mail-ingress` + blocked `mail_track`) and then sit forever: ingress cannot send, project tracks default-block, and `project-*` must not `nylas_send_message`.

**Fix (scheduling analog):** after filing, path **D** spawns a **ready** task on board **`ea-owner-reply`** (`kind: owner_reply`, skill **`ea-owner-reply`**). The worker does the ask, then **`nylas_send_message`** on that thread. Ingress stays send-free. `mail_create_track_task` still default-blocks (waiting on a counterparty).

| Piece | Detail |
|-------|--------|
| Eligibility | Nylas + `from` is owner + track + **not** scheduling path A; skip `owner_sent_update` ([`ownerReplyEligibility.ts`](../../src/ea/ownerReplyEligibility.ts)) |
| Create | Assignee → **ready**; thread_id dedup → `existing_thread`; **no** post-create block |
| Handoff | Later mail on the same thread → `owner_reply_handoff_task` (unblock if blocked) |
| MCP | `owner_reply_list_tasks`, `owner_reply_create_task`, `owner_reply_handoff_task` |
| REST | `GET/POST /api/ea/owner-reply/tasks`, `POST …/tasks/:taskId/handoff` |
| Boards | `ea-owner-reply` in `EA_KANBAN_BOARDS` + no-autodecompose patch set |
| Skill | [`ea-owner-reply`](../../integrations/hermes/skills/executive-assistant/ea-owner-reply/SKILL.md); playbook **2.20.0** path D |
| Test | `npm run test:owner-reply` |

**Out of scope:** Gmail delete/trash opt-in, unblocking existing `mail_track` cards, global ready-task sweep, sends from `project-*`.

Spec: [`executive-assistant.md`](../executive-assistant.md) · MCP table: [`connectors.md`](../connectors.md#connectors-mcp-http-8795).

## Headline: last30days — Watching, QueryPlan, honest engagement

Research Results no longer show mixed `{n} eng`. Cluster cards use per-source native units and sort by relevance then log-comparable engagement. **Watching** (renamed Watchlist) is a business-user list + vs-average watch report (7d window, ≥3 runs). Fleet X search uses **xquik CP relay** (`POST /api/instances/xquik/proxy`); self-host pastes `XQUIK_API_KEY`. Store/Briefings/Doctor moved under Settings.

**Watching cron (fix):** Joshu boot now calls `syncAllAppManifestCronJobs` and writes no-agent scripts into `~/.hermes/scripts/`. Daily watches run at 08:00 local via Hermes job `last30days: watchlist daily`; weekly on Mondays. Previously the manifest job was never registered and `last30days-watchlist-run.sh` did not exist.

**jChat Watching tools:** `joshu-last30days` plugin registers `last30days_watch_list` / `_add` / `_remove` / `_report` / `_run` / `_run_all` (same invoke contract as `last30days_research`). Skills `last30days-chat` and `last30days-gui` tell the agent when to call them.

**Writing style (saved brief):** Results stays JSON cluster cards. The `.md` under `research/last30days/` applies the same audience register as upstream `--register` (exec / dev / creator / eli5): section order, cluster budget, source emphasis.

**Clustering / Results ordering:** Joshu patches `cluster.py` (lower similarity threshold for opinion/comparison). GUI and saved brief sort by **relevance** then engagement; items below **0.45** `relevance_score` are filtered when scores exist; event topics drop other-city Tech Week hits. See [`agentReportFormat.ts`](../src/last30days/agentReportFormat.ts).

**Persistent last30days state:** Runs, query plans, plan-runtime, watch snapshots, Settings, engine store, and memory live under `{AROZ_DATA}/files/users/<user>/.joshu/last30days/` ([`statePaths.ts`](../src/last30days/statePaths.ts)) on the `joshu_arozos` volume. Legacy paths migrated once on boot. Engine `store.py` honors `LAST30DAYS_SHARE_DIR` via [`patch-last30days-share-dir.py`](../scripts/patch-last30days-share-dir.py).

**Host-side QueryPlan:** [`queryPlan.ts`](../src/last30days/queryPlan.ts) classifies topics (named entity / **event** / concept / comparison), builds JSON via **OpenRouter** (heuristics fallback), passes `--plan` before every research and watch run. Concept/event topics exclude TikTok/Instagram/**jobs** via `--search=`. Host-planned runs clear Simple/`--quick` so the engine does not collapse to one subquery and drop X. Plans persist on `watchingAdd` for cron replay. GUI, jChat, and plugin tools stay topic-only — skills `last30days-chat` 0.3.0 / `last30days-gui` 0.4.3 document automatic planning.

Docs: [`last30days-user-guide.md`](../last30days-user-guide.md) · [`last30days-arozos-app.md`](../last30days-arozos-app.md#queryplan-host-side--transparent-to-gui--jchat).

## Desktop & shell UX

### Float-window session (refresh)

Refreshing the ArozOS desktop no longer drops open apps. [`aroz-desktop-window-session.js`](../../arozos/web-overlays-vanilla/aroz-desktop-window-session.js) stores window URL/geometry/z-order (and min/max, jChat docked/floating) in `sessionStorage` and restores after init. Same-tab only; logout / account switch clears. See [`design/README.md`](../design/README.md#float-window-session-restore-refresh).

### jWeb: idle shutdown + warm-on-open + scroll bridge

Keep `BROWSER_IDLE_TIMEOUT_MS=300000` (CPU) but relaunch Firefox when jWeb opens. Default start URL **`https://joshu.me/`**. Host wheel / Arrow / Page keys go through `POST /joshu/api/camofox/scroll` (`public/vnc-scroll.js`, rate-limited). See [`hitl-camofox-notes.md`](../hitl-camofox-notes.md).

### jTerm: resize blink gate

PTY resize only on ≥4px host delta (200ms debounce) + stable scrollbar gutter. Live boxes load ArozOS volume `subservice/jterm/app/` — use `scripts/hotpatch-jterm.sh` when `dist/jterm` is ahead of the volume. See [`jterm-arozos-app.md`](../jterm-arozos-app.md).

### jChat: icon vs tray windows

jChat is no longer a singleton. **Desktop icon** opens a new **floating** window with a fresh Hermes session. **Taskbar avatar** toggles one **docked** companion (`jp-jchat-docked`). **Undock** pops that docked window free; next tray click starts a new docked session. Tray mic/VU stay on the docked iframe.

Doc: [`hermes-chat-arozos-app.md`](../hermes-chat-arozos-app.md#multiple-windows-icon-vs-tray).

### jChat SSE through Caddy

Long Hermes turns were dying at the edge (idle timeout / buffered proxy) and jChat marked the assistant **done** with an empty bubble.

| Change | Detail |
|--------|--------|
| [`src/httpSse.ts`](../../src/httpSse.ts) | Shared SSE headers, `sseSend` / `sseData`, **15s comment heartbeats** |
| Chat + AG-UI + last30days run SSE | Heartbeats while the model is quiet |
| Caddy `/joshu/*` | `flush_interval -1` + 1h HTTP read/write timeouts |
| jChat client | Treat missing `done`/`error` as **dropped connection**, not empty success |

Docs: [`nylas-agent-mailbox.md`](../nylas-agent-mailbox.md).

### EA Kanban + Nylas (commit `c1cc83c`)

- **Single-worker EA boards** — skip Hermes `auto_decompose` on `ea-scheduling` / `ea-mail-ingress` / `ea-sched-ingress` / `ea-owner-reply`. Block-loop stays **blocked**, not triage.
- **Live Nylas parent for replies** — authorize `nylas_send_message` from live parent when mail mirror is missing.

### Slack / Telegram session idle (30 minutes)

Joshu box default: Slack and Telegram **idle-reset after 30 minutes**. jChat (`api_server`) stays continuous. Override `JOSHU_HERMES_MESSAGING_IDLE_MINUTES` (`0` / `none` to disable). [`hermesMessagingSessionReset.ts`](../../src/hermesMessagingSessionReset.ts).

### Voice / Langfuse user-quote backfill (commit `02c7282`)

Realtime often calls `think` before STT lands. Browser and phone now **backfill `User said:`** from late STT so Langfuse shows the spoken utterance.

## Migration (0.1.40 → 0.1.41)

1. **Pull rebuilt images** — `ghcr.io/db-aeon/joshu-sandbox:0.1.41` or `joshu-oss:0.1.41` (2026-08-22 digest includes CWM JS).

3. **Crash-looping 0.1.41 box** — same as (2), or copy `deploy/hotfixes/cwm-backend-js/*` into host `dist/excalidraw/` then recreate.
4. **Share Chat on 0.1.40** — ensure `dist/shareChat/ui/index.html` present (overlay or pull 0.1.41).
5. **EA cron duplicates** — `POST /joshu/api/onboarding/resync-ea-crons` or Welcome re-run after upgrade.
6. **Fleet password reset** — use CP email flow; expect brief 502 during stack bounce.
7. **Self-host docs** — use updated [`hetzner-quickstart.md`](../vps-sandbox/hetzner-quickstart.md) (DigitalOcean section, `JOSHU_AROZ_USER`, health 503).
