## What changed since 0.1.46

### Owner phone + delivery hardening

- **Call gate** — Twilio-signed webhooks, passphrase or optional PIN, single-use unlock token before the media stream reaches Gemini Live
- **Owner outbox** — more reliable owner-facing SMS/voice delivery when work finishes asynchronously
- **Voice think budget** — caps expensive think turns on PSTN so the call stays responsive
- **CDP relay** — browser sidecar relay improvements used by voice-adjacent tooling

See [voice-realtime.md](../vps-sandbox/voice-realtime.md#call-gate-passphrase--pin) and [twilio-self-host.md](../vps-sandbox/twilio-self-host.md).

### Gate clips aligned with Gemini Live

Lock and gate prompts are pre-rendered with the **Live model configured for your box**, with verbatim checking in the clip manifest. Fallback: `gemini-3.8-flash-tts`.

### Twilio architecture cleanup

Joshu no longer hosts a parallel **media-stream** pipeline; **voice-realtime** is the only speech-to-speech entry for PSTN.

## Upgrade (existing VPS)

```bash
# On the box — align with deploy/RELEASE.json
sudo sed -i 's|^JOSHU_RELEASE_VERSION=.*|JOSHU_RELEASE_VERSION=0.1.47|' /etc/joshu/instance.env
sudo sed -i 's|^JOSHU_IMAGE_REF=.*|JOSHU_IMAGE_REF=ghcr.io/db-aeon/joshu-oss:0.1.47|' /etc/joshu/instance.env
sudo sed -i 's|^JOSHU_VOICE_IMAGE_REF=.*|JOSHU_VOICE_IMAGE_REF=ghcr.io/db-aeon/joshu-oss-voice-realtime:0.1.47|' /etc/joshu/instance.env

cd /opt/joshu/deploy
docker pull ghcr.io/db-aeon/joshu-oss:0.1.47
docker pull ghcr.io/db-aeon/joshu-oss-voice-realtime:0.1.47
docker compose -f docker-compose.yml --env-file /etc/joshu/instance.env up -d --force-recreate joshu-stack
docker compose -f docker-compose.yml --env-file /etc/joshu/instance.env --profile voice-rt up -d --force-recreate voice-realtime
```

Then sync host `dist/` if you bind-mount it:

```bash
JOSHU_IMAGE_REF=ghcr.io/db-aeon/joshu-oss:0.1.47 JOSHU_RELEASE_VERSION=0.1.47 \
  bash /opt/joshu/scripts/sync-dist-from-image.sh
```

Fresh installs: [hetzner-quickstart.md](../vps-sandbox/hetzner-quickstart.md) (pull tag **`0.1.47`**).
