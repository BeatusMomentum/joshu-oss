## Headline: last30days desktop app

Community research app over the [last30days-skill](https://github.com/mvanhorn/last30days-skill) engine.

| Layer | Path |
|-------|------|
| React GUI | `apps/last30days/` |
| ArozOS subservice | `arozos/subservice/last30days/` |
| Server / runner | `src/last30days/` |
| Hermes plugin | `.hermes/plugins/joshu-last30days/` |
| Vendored engine | `integrations/last30days-skill/` (pinned via `.pin`) |

**Policy:** ScrapeCreators for social/YouTube; no yt-dlp, browser cookies, or X/Twitter. Web via Exa when `EXA_API_KEY` set, else keyless DuckDuckGo. Python ≥ 3.12 (`LAST30DAYS_PYTHON` in image). Planner/rerank via box OpenRouter (`google/gemini-3.1-flash-lite`).

**Self-host:** Paste your own ScrapeCreators key in Settings or `instance.env` — no CP relay.

**Multimodal:** Uses the new Joshu SDK stack — see [Joshu SDK](#joshu-sdk) below.

**On completion:** Markdown report → `research/last30days/` (gbrain-indexed) · proactive Hermes session reply · SSE push to open jChat tabs.

**Patches:** Clustering + engagement sort (`patch-last30days-clustering.py`); optional SC relay patch for fleet proxy mode.

**API:** `/joshu/api/last30days/*` — status, config, research, runs + SSE, doctor, watchlist/store/briefings.

Docs: [`last30days-user-guide.md`](../last30days-user-guide.md) · [`last30days-arozos-app.md`](../last30days-arozos-app.md)

## Joshu SDK

Consolidated improvements to the app manifest contract, client packages, and box runtime. Reference implementation: **last30days**.

### `@joshu/app-sdk`

| Change | Detail |
|--------|--------|
| **`validateMultimodalProfile()`** | Stricter check for chat + GUI + headless apps: requires `apiPrefix`, `agent.skill`, `guiActions[]`, `actions[]`; rejects `headless: true` |
| **CLI `--multimodal`** | `joshu-app validate --multimodal path/to/joshu.app.json` |
| **Manifest fields in use** | `delivery` (`onComplete`, `outputDir`) and `cron.jobs[]` on `joshu.app.json` — consumed by runtime; not yet in TS types |

### `@joshu/app-agent`

| Change | Detail |
|--------|--------|
| **`JoshuMultimodalApp`** | New shell component — wires `useAppAgentChatSession` + `JoshuEmbeddedAppAgent` + `guiActions` + optional voice + `promptRequest` (app-originated chat turns, e.g. job complete) |
| **Reference pattern** | `last30daysAppManifest.ts` (browser mirror of `joshu.app.json`) + `createLast30daysGuiActions()` handlers bound to a `guiRef` |

### Box runtime (SDK contract)

| Module | Change |
|--------|--------|
| **`appInvokeRegistry`** | Auto-registers `agent.actions[]` → REST proxies on `apiPrefix`; explicit `registerAppAction()` wins. Supports async POST (`research`, …) with `wait` + run polling |
| **`appCronSync`** | Upserts `cron.jobs[]` from manifest into Hermes cron bridge |
| **`appRegistry`** | Scans multiple subservice roots: repo `arozos/subservice`, `$AROZ_DATA/subservice`, `$AROZ_TEMPLATE/subservice` (VPS hotpatch-safe) |
| **`appInvokeApi`** | Forwards `x-hermes-session-key` / `x-hermes-session-id` (or body fields) into invoke args for async delivery |
| **`appGuiActionApi`** | Accepts OpenAI-style `arguments` alias when parsing Hermes `app_gui_action` tool calls |
| **`appOwnerDelivery`** | `notifyOwnerAppEvent()` — Slack/Telegram via Composio (infra present; not wired in last30days runner yet) |
| **`hermesChatSessionPush`** | SSE `transcript_updated` on `GET /api/hermes-chat/sessions/:id/events` — jChat refreshes when async jobs append to SessionDB |
| **Removed** | `POST /api/hermes-chat/tts` — jChat speech-output TTS path dropped (S2S-only voice) |

### Hermes `joshu-app-gui` plugin

- `validate.py` accepts `arguments` in addition to `args` (LLM schema mismatch fix)

### `@joshu/instance-agent`

| Change | Detail |
|--------|--------|
| **DO IPv4** | Resolves public IP from link-local metadata when `VPS_IPV4` unset |
| **`send_owner_email` command** | CP → box owner email via localhost `POST /api/instance/send-owner-email` |
| **Command ack** | Returns `result` payload on success (messageId, placeholders filled, etc.) |

### `@joshu/voice-realtime`

| Change | Detail |
|--------|--------|
| **`instantProgressAck`** | Pre-rendered PCM clip for immediate think ack (`getInstantProgressAckPcm()`, box-local path under `~/.joshu/voice/`) |
| **PSTN unlock** | Passphrase-only `think_tool` unlock no longer starts empty brain job; awaits restated intent |
| **Default model** | `deepseek-v4-flash-0731` |

### Unchanged packages

`@joshu/platform-data`, `@joshu/jchat-ui`, `@joshu/box-state`, `@joshu/voice-client`, `@joshu/email-signature`, `@joshu/design-system` — no code changes in this release.
