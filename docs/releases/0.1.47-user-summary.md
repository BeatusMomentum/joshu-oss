# Joshu OSS 0.1.47 — what’s in this release

## Safer phone access to your box

Self-hosted boxes with Twilio keep the **call gate**: you prove it’s you (spoken passphrase or optional PIN) before the AI joins the call. This release **hardens** how owner messages and async job results reach you on SMS and voice — fewer edge cases where a completion gets lost.

## Gate prompts that match your voice

The short system prompts you hear while unlocking the call are generated with the **same Gemini Live setup** as the conversation, so the tone stays consistent.

## Cleaner Twilio wiring

One path for phone audio: **voice-realtime** behind Caddy. Joshu dropped an older duplicate media-stream handler that could confuse upgrades.
